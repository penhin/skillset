THROWAWAY LOGIC PROTOTYPE

Skillset 的“加入、覆盖、移除、恢复”是否真的可逆？

这个实验不修改真实文件。它模拟两个目标 Coding Agent 原本都拥有 review，再由共同 Skillset 覆盖、发生本机漂移、最后移除并恢复原始内容的全过程。

要验证的状态模型：受管 skill 覆盖同名 skill 前必须保留逐 agent 快照；移除 Skillset 后恢复快照，而不会删除无关的本地 skills。

自由操作

每次点击都会更新右侧完整状态。先试“同步受管 review”，再试“移除并恢复”。
